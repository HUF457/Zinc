# Support

[简体中文](SUPPORT.zh-CN.md) | English

Use GitHub Issues for reproducible bugs and focused feature requests. Security
vulnerabilities must follow [`SECURITY.md`](SECURITY.md), not the public issue
tracker.

Before filing a bug:

1. Upgrade to the newest available Zinc release.
2. Read [`docs/TROUBLESHOOTING.md`](docs/TROUBLESHOOTING.md).
3. Search existing issues.
4. Reproduce with the smallest safe test case.

Include the Zinc version shown in Settings > About, Windows version, install
method, shell executable, exact steps, expected/actual behavior, and the checks
already attempted.

Logs and screenshots are optional. Before attaching them, remove usernames,
home directories, working directories, command history, environment variables,
tokens, hostnames, IP addresses, repository names, and personal files. When in
doubt, describe the symptom in text instead.

Support is provided by maintainers and community contributors on a best-effort
basis. No response time or compatibility guarantee is implied.
