# WinUI Native Legacy Archive

This directory preserves isolated WinUI/WebView2 and WPF feasibility experiments
from the project's migration research.

It is not the active product line. The active app is the Electron implementation
in `../../app`.

Contents:

- `CompositionWebView/` - feasibility spike around WinUI/WebView2 and WPF.

Use this archive only as historical research evidence. New feature work should
happen in `app/`.
