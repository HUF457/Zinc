# Zinc 0.6.3

Zinc is a **lightweight multi-shell Windows terminal launcher**: vertical tab
rail, Acrylic-style window, PowerShell-first multi-shell discovery, and low
background overhead. Windows 10 / 11 x64. AGPL-3.0-only.

## Which file do I download?

**`Zinc-0.6.3-Setup.exe`** — the only installer. Per-user by default; no
administrator rights required for a normal install.

Other assets are the audit trail: `SHA256SUMS.txt`, `zinc-0.6.3.cdx.json`
(CycloneDX SBOM), `THIRD_PARTY_NOTICES-0.6.3.md`, `ASSET_PROVENANCE.md`,
`LICENSE`, plus `latest.yml` / `.blockmap` for the in-app updater.

## Zinc is not code-signed — verify before you run it

```powershell
Get-FileHash .\Zinc-0.6.3-Setup.exe -Algorithm SHA256
```

Compare against the line for `Zinc-0.6.3-Setup.exe` in `SHA256SUMS.txt` on this
page. Only if it matches: **More info → Run anyway**. If it does not match,
delete the file.

## What changed

- **Copy polish** in Settings, About, and the update dialog (Chinese and English):
  shorter labels, clearer opacity / shell / session-restore wording.
- About tagline aligned with the product pitch (lightweight Windows terminal,
  vertical tabs by default) — not an “Electron shell” marketing line.
- AI conversation resume copy states clearly: Zinc types the local
  `continue` / `resume` command only; it does not run an agent for you or upload
  terminal content.
- Installer upgrade matrix is pinned to the reviewed public `v0.6.2` setup.
