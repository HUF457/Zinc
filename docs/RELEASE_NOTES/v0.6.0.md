# Zinc 0.6.0

Zinc is a **lightweight multi-shell Windows terminal launcher**: vertical tab
rail, Acrylic-style window, PowerShell-first multi-shell discovery, and low
background overhead. Windows 10 / 11 x64. AGPL-3.0-only.

## Which file do I download?

**`Zinc-0.6.0-Setup.exe`** — the only installer. Per-user by default; no
administrator rights required for a normal install.

Other assets are the audit trail: `SHA256SUMS.txt`, `zinc-0.6.0.cdx.json`
(CycloneDX SBOM), `THIRD_PARTY_NOTICES-0.6.0.md`, `ASSET_PROVENANCE.md`,
`LICENSE`, plus `latest.yml` / `.blockmap` for the in-app updater.

## Zinc is not code-signed — verify before you run it

```powershell
Get-FileHash .\Zinc-0.6.0-Setup.exe -Algorithm SHA256
```

Compare against the line for `Zinc-0.6.0-Setup.exe` in `SHA256SUMS.txt` on this
page. Only if it matches: **More info → Run anyway**. If it does not match,
delete the file.

## What changed

- Positioned as a lightweight multi-shell launcher; removed the AI usage status
  bar and its background polling.
- **NSIS-only** distribution — the nested Electron custom installer wrapper is
  gone (no more ~200 MB double package).
- Removed AOD / OLED burn-in / Linux brightness settings (kiosk leftovers).
- Session restore can resume Grok Build via `grok --continue` (with Claude /
  Codex resume).
- Test shells no longer pollute the developer’s global PowerShell / bash history.
- Full-screen TUI black backgrounds stay transparent over Acrylic when terminal
  opacity is 0.

## Language

English and Simplified Chinese UI are included.

## 本版变化

- 定位为轻量多 shell 启动器；移除 AI 用量状态栏及其后台轮询。
- **仅 NSIS 安装包**，去掉套了一层 Electron 的自定义安装器（不再 ~200 MB 双包）。
