# Zinc 0.6.1

Zinc is a **lightweight multi-shell Windows terminal launcher**: vertical tab
rail, Acrylic-style window, PowerShell-first multi-shell discovery, and low
background overhead. Windows 10 / 11 x64. AGPL-3.0-only.

## Which file do I download?

**`Zinc-0.6.1-Setup.exe`** — the only installer. Per-user by default; no
administrator rights required for a normal install.

Other assets are the audit trail: `SHA256SUMS.txt`, `zinc-0.6.1.cdx.json`
(CycloneDX SBOM), `THIRD_PARTY_NOTICES-0.6.1.md`, `ASSET_PROVENANCE.md`,
`LICENSE`, plus `latest.yml` / `.blockmap` for the in-app updater.

## Zinc is not code-signed — verify before you run it

```powershell
Get-FileHash .\Zinc-0.6.1-Setup.exe -Algorithm SHA256
```

Compare against the line for `Zinc-0.6.1-Setup.exe` in `SHA256SUMS.txt` on this
page. Only if it matches: **More info → Run anyway**. If it does not match,
delete the file.

## What changed

- **Drag to reorder tabs** on the left rail: free horizontal and vertical
  follow-hand ghost, smooth sibling gap, clear insertion line when the drop
  slot is not the origin.
- Drop targeting uses the floating card’s center (not the cursor tip) so
  inserts that already look “between rows” actually take.
- Tab numbers stay positional `1…n`; rail labels are non-selectable.
- Installer upgrade matrix is pinned to the reviewed public `v0.6.0` setup.

Full history: [CHANGELOG.md](https://github.com/HUF457/Zinc/blob/main/CHANGELOG.md)

## 本版变化

- **左侧标签可拖拽重排**：自由水平/垂直跟手幽灵层、同级让位空隙、插入指示线。
- 落点按幽灵卡片中心（非光标尖）判定，视觉上已在两行之间时会真正插入。
- 标签序号始终为位置 `1…n`；标签文字不可选中。
- 安装升级矩阵钉死到已审核的公开 `v0.6.0` 安装包。
