# Zinc 0.6.2

Zinc is a **lightweight multi-shell Windows terminal launcher**: vertical tab
rail, Acrylic-style window, PowerShell-first multi-shell discovery, and low
background overhead. Windows 10 / 11 x64. AGPL-3.0-only.

## Which file do I download?

**`Zinc-0.6.2-Setup.exe`** — the only installer. Per-user by default; no
administrator rights required for a normal install.

Other assets are the audit trail: `SHA256SUMS.txt`, `zinc-0.6.2.cdx.json`
(CycloneDX SBOM), `THIRD_PARTY_NOTICES-0.6.2.md`, `ASSET_PROVENANCE.md`,
`LICENSE`, plus `latest.yml` / `.blockmap` for the in-app updater.

## Zinc is not code-signed — verify before you run it

```powershell
Get-FileHash .\Zinc-0.6.2-Setup.exe -Algorithm SHA256
```

Compare against the line for `Zinc-0.6.2-Setup.exe` in `SHA256SUMS.txt` on this
page. Only if it matches: **More info → Run anyway**. If it does not match,
delete the file.

## What changed

- **Update UX**: packaged builds quietly check GitHub Releases after startup; an
  update badge appears next to Settings when a newer version is known; a centered
  dialog shows notes and download progress.
- Updates **download automatically** when found. Installing still requires an
  explicit **Restart to update** action (sessions are not closed silently).
- Settings → About keeps a **single** check / restart control instead of separate
  download and install buttons.
- Terminal **OSC 8 / CLI hyperlinks** open in the system browser immediately (no
  dangerous-link confirm dialog that could not open a window).
- Installer upgrade matrix is pinned to the reviewed public `v0.6.1` setup.

Full history: [CHANGELOG.md](https://github.com/HUF457/Zinc/blob/main/CHANGELOG.md)
