Zinc is a Windows terminal: vertical tab rail, session restore, Acrylic surface,
and a status bar that reads the Claude Code / Codex usage already sitting on your
machine. Windows 10 / 11 x64. AGPL-3.0-only.

## Which file do I download?

**`Zinc-0.5.0-Setup.exe`** — this is the one. A normal installer; per-user by
default, no administrator rights needed.

`Zinc-0.5.0-Installer.exe` embeds that same Setup and adds a wizard around it
that detects what is already installed and handles overwrite installs,
reinstalls, downgrades and uninstalls. It can perform a first install too, but it
is roughly twice the size and gains you nothing on a clean machine — reach for it
when an install needs repairing, not to get started. It is **not** a portable
build of Zinc: it installs Zinc like Setup does.

The remaining assets are the audit trail: `SHA256SUMS.txt` (checksums),
`zinc-0.5.0.cdx.json` (CycloneDX SBOM), `THIRD_PARTY_NOTICES-0.5.0.md`,
`ASSET_PROVENANCE.md`, `LICENSE`, plus `latest.yml` / `.blockmap` used by the
in-app updater.

## Zinc is not code-signed — verify before you run it

Zinc has no Authenticode signature, so SmartScreen will most likely stop the
first run with "Windows protected your PC" (exactly what it does depends on
reputation and your machine's policy). Before you click through that, prove the
file is the one we published:

```powershell
Get-FileHash .\Zinc-0.5.0-Setup.exe -Algorithm SHA256
```

Compare the value against the line for `Zinc-0.5.0-Setup.exe` in
`SHA256SUMS.txt` on this page. Only if it matches: **More info → Run anyway**.
If it does not match, delete the file.

A checksum proves the file reached you intact. It is not a code signature and
does not prove publisher identity — that is exactly why the source, the SBOM and
the third-party notices ship with every release.

## What's in 0.5.0

- Shell discovery for PowerShell 7, Windows PowerShell, Command Prompt, Git Bash
  and installed WSL distributions, with per-tab shell selection and a
  configurable default. PowerShell 7 is recommended, not required — without it
  Zinc falls back to Windows PowerShell or Command Prompt.
- Session restore: tab order, selected tab and the working directory captured at
  exit. When a tab was running Claude Code or Codex — and AI conversation resume
  is on, which it is by default — Zinc reopens it with `claude --continue` /
  `codex resume --last`.
- Status bar reading local Claude Code / Codex usage — model, effort, context,
  the 5-hour and 7-day windows, and cost where the tool reports it (Claude does;
  Codex does not expose cost). It appears when one of those tools is running in
  the active tab, and stays hidden otherwise. Read-only; nothing is uploaded.
- Vertical tab rail, Acrylic surface with separate rail/terminal opacity, six
  colour schemes with light and dark variants, 18 rebindable actions.
- Updates are manual and opt-in: **Settings → About → Check for updates**. Zinc
  never contacts the network on its own.
- Custom installer with payload integrity verification, and a graceful-shutdown
  policy that asks a running Zinc to close instead of killing your work.

Full history: [CHANGELOG.md](https://github.com/HUF457/Zinc/blob/main/CHANGELOG.md)

## Known limits

- No first-run walkthrough: Zinc opens a shell and gets out of the way.
- The restored working directory is the one captured when Zinc exited; a `cd`
  performed inside the shell is not always visible to Zinc.
- AI conversation resume attaches to each tool's most recent conversation, not to
  a per-tab conversation id.
- Uninstalling removes the program and its shortcuts but keeps your settings,
  session state and pasted images in `%APPDATA%\zinc`. Delete that folder
  yourself for a clean wipe.

## 没做代码签名——先校验，再运行

Zinc 没有 Authenticode 签名，所以 SmartScreen 大概率会用「Windows 已保护你的电脑」
挡住首次运行（具体拦不拦，取决于文件信誉和你机器的策略）。在点"仍要运行"之前，
先证明文件就是我们发布的那一个：

```powershell
Get-FileHash .\Zinc-0.5.0-Setup.exe -Algorithm SHA256
```

和本页 `SHA256SUMS.txt` 里 `Zinc-0.5.0-Setup.exe` 那一行逐字比对。一致，才
**更多信息 → 仍要运行**；对不上，直接删掉。

校验和只能证明文件没被改动过，它不是代码签名，证明不了发布者身份——所以源码、
SBOM 和第三方许可清单每次发布都随包附上。

## 已知边界

- 没有首次运行向导：Zinc 开一个 shell，然后让开。
- 恢复的工作目录是 Zinc 退出时捕获到的那个；你在 shell 里 `cd` 过去的目录，Zinc 不一定
  看得到。
- AI 对话续接接的是各工具"最近一次对话"，不是按标签绑定的会话 id。
- 卸载会删掉程序和快捷方式，但保留 `%APPDATA%\zinc` 里的设置、会话状态和粘贴的图片。
  要彻底清干净，自己删掉那个目录。
