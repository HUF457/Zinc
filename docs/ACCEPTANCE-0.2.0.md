# Historical Acceptance Summary: 0.2.0

This document is retained only as a sanitized record of the Electron migration.
It is not the current release checklist.

The 0.2.0 milestone established the Electron main process, context-isolated
preload boundary, React renderer, xterm.js terminal hosts, `node-pty` sessions,
vertical tab rail, settings persistence, session restore, Acrylic-style window,
and packaged Windows application path.

Historical acceptance used source checks, packaged startup checks, terminal
input/output exercises, resize/scroll behavior, settings persistence, and visual
comparison. Original development screenshots and machine-specific logs are not
part of the public record because they contained real terminal content and local
paths.

For current acceptance, use [`RELEASE.md`](RELEASE.md),
[`INSTALLER.md`](INSTALLER.md), and [`TROUBLESHOOTING.md`](TROUBLESHOOTING.md).
